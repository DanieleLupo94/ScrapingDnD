ISTRUZIONI RAPIDE (v2.0):
=========================

Windows:
  1. Doppio click su run.bat
  2. Seleziona opzione 2 (Scraper SAFE) ⭐

Linux/Mac:
  1. chmod +x run.sh
  2. ./run.sh
  3. Seleziona opzione 2 (Scraper SAFE) ⭐
  
Oppure manualmente:
  pip install -r requirements.txt
  python dnd_scraper_safe.py      ← CONSIGLIATO!
  python dnd_parser.py
